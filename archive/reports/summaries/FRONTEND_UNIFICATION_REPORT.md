## 📊 技术改进详情

### 设计系统架构
```
frontend-vue/src/
├── constants/
│   └── design-system.ts          # 设计令牌和工具函数
├── components/
│   └── ui/
│       ├── StandardCard.tsx      # 标准卡片组件
│       ├── StandardPage.tsx      # 标准页面组件
│       ├── StandardTable.tsx     # 标准表格组件
│       └── index.ts              # 组件导出
├── services/
│   └── dataService.ts           # 统一数据服务
└── styles/
    ├── global-design-styles.css # 全局设计样式
    └── design-tokens.css        # CSS设计令牌
```

### 组件使用模式
```typescript
// 旧模式：硬编码样式和模拟数据
<Card style={{ padding: '16px', background: '#fff' }}>
  {mockData.map(item => <div key={item.id}>{item.name}</div>)}
</Card>

// 新模式：使用设计系统和真实数据
<StandardCard variant="statistic" color={DESIGN_TOKENS.colors.primary}>
  {data.map(item => <div key={item.id}>{item.name}</div>)}
</StandardCard>
```

### API调用模式
```typescript
// 旧模式：直接fetch和模拟数据
const fetchLawyers = async () => {
  if (isDevMode) {
    return mockLawyers; // 模拟数据
  }
  return await fetch('/api/lawyers');
};

// 新模式：统一数据服务
const fetchLawyers = async () => {
  return await dataService.getLawyers(params);
};
```
