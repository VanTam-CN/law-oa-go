# 独立服务器文件归档

**归档日期**: 2025-10-23
**归档原因**: 这些是独立的测试服务器和演示文件，不是核心系统的一部分。

## 归档内容

### standalone_conflict_server/ 目录
- 独立的冲突检测服务器
- 用于隔离测试冲突检测功能
- 包含完整的Go模块和测试代码

### standalone_conflict_demo.go 文件
- 独立的冲突检测演示
- 用于展示冲突检测API功能
- 不依赖于完整系统

## 恢复说明

如果需要重新运行独立服务器：
1. 从此归档恢复文件
2. 进入目录运行 `go run main.go`
3. 测试客户端使用 `go run test_client.go`

## 清理效果

- 简化项目根目录
- 减少混淆（避免与主服务器冲突）
- 保持代码整洁
