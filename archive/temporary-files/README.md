# 临时文件归档

**归档日期**: 2025-10-23
**归档原因**: 各种临时配置文件、脚本文件和多余的Docker配置，这些是开发过程中的临时文件。

## 归档内容

### 多余的Docker配置
- `docker-compose.*.yml` - 非主要的Docker编排文件
- `Dockerfile.*` - 非主要的Dockerfile
- 各种环境和测试的Docker配置

### 临时启动脚本
- `start-*.sh` - 各种启动脚本
- `quick-*.sh` - 快速启动脚本
- `run*.sh` - 运行脚本

### 临时配置文件
- `config.*.yaml` - 非主要配置文件
- `.env.*` - 非主要环境变量文件
- 各种测试和开发配置

### 二进制和构建文件
- `main` - 编译后的二进制文件
- `test_build` - 测试构建产物
- 各种编译和测试输出

## 恢复说明

如果需要恢复特定配置：
1. 检查主要配置文件（docker-compose.yml, Dockerfile等）
2. 从git历史查找特定配置
3. 根据需要重新创建配置

## 清理效果

- 减少配置文件混乱
- 避免使用错误的配置文件
- 保持项目结构清晰
