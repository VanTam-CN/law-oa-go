# 测试文件归档

**归档日期**: 2025-10-23
**归档原因**: 大量的临时测试文件、调试文件和演示文件，这些文件对核心功能不必要。

## 归档内容

### Go测试文件
- `test_*.go` - 功能测试文件
- `debug_*.go` - 调试用的Go文件
- `*_test.go` - 单元测试文件（非标准的测试文件）
- `create_*_user.go` - 创建测试用户的脚本
- `init_*_data.go` - 初始化测试数据的脚本

### JavaScript测试文件
- `test_*.js` - 前端测试脚本
- `debug_*.js` - 调试用的JavaScript文件
- `*_test.js` - 各种测试脚本
- `verify_*.js` - 验证脚本

### HTML测试文件
- `test_*.html` - 测试页面
- `debug_*.html` - 调试页面
- `quick_*.html` - 快速测试页面

### 配置和演示文件
- `conflict_api_demo.go` - API演示文件
- `quick_*_test.go` - 快速测试文件
- `simple_*.go` - 简化测试文件

## 恢复说明
