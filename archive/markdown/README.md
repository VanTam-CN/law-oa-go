## 🗂️ 分类说明

### 📊 historical-reports/
- **内容**: 历史修复报告、测试报告、项目总结
- **特点**: 记录项目开发过程中的重要里程碑
- **价值**: 历史参考和问题解决记录

### 📚 outdated-docs/
- **内容**: 过时的技术文档、API文档、配置指南
- **特点**: 已被新版本替代的旧文档
- **价值**: 了解项目演进过程

### 🧪 test-docs/
- **内容**: 临时测试报告、验证文档、系统测试记录
- **特点**: 开发过程中产生的临时文档
- **价值**: 测试历史和验证记录

### 🔄 duplicate-docs/
- **内容**: 重复的规范文档、已整合的模板
- **特点**: 功能重复或已被其他文档替代
- **价值**: 避免文档混乱

### 🤖 ai-frameworks/
- **内容**: BMAD、Kiro等AI开发框架文档
- **特点**: 已整合到主项目或不再使用
- **价值**: AI开发流程参考

### 🛠️ development-guides/
- **内容**: 过时的开发指南、工具使用说明
- **特点**: 开发工具或流程已更新
- **价值**: 开发历史参考
