# Archive Directory

This directory contains archived files from the Law OA Go project development process.

## Directory Structure

### 📁 `debug/`
- **database/**: Database debugging and diagnostic scripts
- **api/**: API debugging tools
- **frontend/**: Frontend debugging utilities

### 📁 `tests/`
- **go/**: Go language test files and API integration tests
- **javascript/**: JavaScript test files and browser tests
- **typescript/**: TypeScript test files and frontend tests
- **integration/**: Integration test scripts
- **e2e/**: End-to-end test files
- **reports/**: Test execution reports and HTML reports
- **scripts/**: Test execution shell scripts and utilities

### 📁 `reports/`
- **fixes/**: Bug fix and issue resolution reports
- **validation/**: System validation and testing reports
- **summaries/**: Development summaries and guides

### 📁 `configs/`
- **environments/**: Environment-specific configuration files
- **temporary/**: Temporary configuration files
- **frontend/**: Frontend configuration archives

### 📁 `scripts/`
- **migration/**: Database migration scripts
- **data-fix/**: Data repair and maintenance scripts

### 📁 `binaries/`
- Compiled binary files from different development phases

### 📁 `logs/`
- Application logs from development and testing phases
