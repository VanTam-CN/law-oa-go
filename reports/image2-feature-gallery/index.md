# Law OA Image2 样例图库

## 说明

- 生成模型：内置 `image2` 路径
- 产物类型：高保真后台页面样例
- 画幅：默认 16:9
- 当前状态：`19 / 19` 已生成并已复制到仓库目录
- 目录结构：
  - `feature-map.md`：功能与批次说明
  - `prompts/`：每张图的独立 prompt
  - `generated/`：已生成图片

## 查看方式

- HTML 浏览：`gallery.html`
- 浏览能力：批次筛选、关键词搜索、标准视图、紧凑视图、汇报模式、演示模式、全屏预览
- 演示模式：按当前筛选结果顺序播放，支持上下页切换、自动播放、`Esc` 退出
- 按批次查看：`generated/batch-01` 到 `generated/batch-04`
- 按 prompt 对照查看：`prompts/` 中的文件名与图片文件名一一对应
- 适合优先翻阅的页面：
  - `batch-01/04-conflict-check-results.png`
  - `batch-02/07-ethical-wall-control.png`
  - `batch-03/10-document-library.png`
  - `batch-04/15-finance-contract-overview.png`
