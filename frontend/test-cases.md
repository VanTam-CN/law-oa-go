# 律所OA系统前端测试用例

## 1. 用户认证和权限管理功能测试

### 1.1 登录功能测试
- **测试目标**: 验证用户登录流程和身份验证
- **测试步骤**:
  1. 访问 `http://localhost:3003/login`
  2. 验证登录页面加载正常
  3. 输入正确的用户名和密码
  4. 点击登录按钮
  5. 验证跳转到仪表盘页面
- **预期结果**: 登录成功后跳转到仪表盘，用户信息显示正确

### 1.2 权限验证测试
- **测试目标**: 验证不同角色的权限控制
- **测试步骤**:

  3. 验证权限显示正常
  4. 以普通用户身份登录
  5. 验证权限限制生效
- **预期结果**: 不同角色看到的功能模块不同，权限控制正确

### 1.3 登出功能测试
- **测试目标**: 验证用户登出功能
- **测试步骤**:
  1. 用户登录状态下点击登出
