# Law OA Image2 MVP 设计原型

这是一个独立静态前端原型，优先覆盖 MVP 闭环、案件管理、客户管理和利益冲突检查。

## 文件

- `index.html`: 原型入口
- `styles.css`: 页面布局、视觉规范和响应式样式
- `app.js`: 原型数据与基础交互

## 使用方式

直接在浏览器打开 `index.html` 即可预览。原型未依赖现有前端构建链，便于设计评审和快速迭代。

## MVP 范围

- 工作台：接案流程、关键指标、待办队列
- 案件管理：案件列表、冲突状态、下一步动作、新建案件抽屉
- 客户管理：客户主数据、别名、联系人、关联方、风险等级
- 利益冲突：接案前检查、命中结果、风险分类、处理建议
