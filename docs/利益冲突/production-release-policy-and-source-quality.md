# 利益冲突生产放行政策与数据源质量配置

## 1. 目的

本文件说明生产环境如何把律所已经签署的冲突政策和权威档案质量证据登记到系统。它不替律所选择适用规则、保留期限、豁免条件或受控动作，也不构成法律意见。

未完成下列两类登记时，`/health/ready` 必须返回未就绪：

1. 一份当前有效、由不同人员分别代表管理和合规职责批准的政策版本；
2. `CASE_ARCHIVE`、`CLIENT_ARCHIVE`、`SUBJECT_REGISTRY`、`RELATION_ARCHIVE` 四类权威来源的完整对账和当前质量证据。

## 2. 政策版本登记

授权人员先在“冲突治理”提交不可修改的政策材料包。主任/管理合伙人与合规负责人必须使用两个不同账号，对同一个 SHA-256 摘要分别确认；第二次有效确认后，服务端才把最终版本写入 `law_firm_compliance_policy_profiles`。材料包、确认记录和最终政策均为追加式证据，记录创建后不得修改或删除；政策变化必须创建新版本，并通过新版本的生效时间替代旧版本。技术管理员无权代签。

每个生效版本必须包含：

- 执业登记地；
- 适用规则名称、版本、发布机关和可核验引用；
- 权威来源政策、个人信息处理依据矩阵、保留政策、豁免政策和受控动作清单的证据引用；
- 外部专项审阅或律所内部确认材料的证据引用；
- 不同的管理批准人和合规批准人；
- 批准、生效、下次复核和可选到期时间；
- 长度为 64 个十六进制字符的 SHA-256 完整性摘要。摘要应针对已签署材料包生成，材料包本身存放在律所批准的文档或档案系统中。

生产健康检查要求当前时间只能命中一个有效的 `APPROVED` 版本。没有有效版本、同时存在多个有效版本、批准人为同一人、材料引用缺失或完整性摘要格式错误，均阻断生产就绪。

## 3. 权威来源质量登记

每个 `conflict_search_scopes` 的 `COMPLETE` 记录除索引对账凭证外，还必须登记：

| 字段 | 含义 |
| --- | --- |
| `source_of_truth` | 律所是否书面确认该来源属于权威来源 |
| `sync_mode` | `REALTIME`、`BATCH` 或 `MANUAL_IMPORT` |
| `max_sync_lag_minutes` | 律所批准的最大同步延迟，必须大于 0 |
| `last_successful_sync_at` | 最近一次成功同步并对账的时间 |
| `minimum_field_coverage_bps` | 最低字段覆盖率，基点制，10000 表示 100% |
| `measured_field_coverage_bps` | 本次测得的字段覆盖率 |
| `maximum_duplicate_rate_bps` | 允许的最高重复率，基点制 |
| `measured_duplicate_rate_bps` | 本次测得的重复率 |
| `quality_owner_id` | 数据质量责任人 |
| `quality_reviewed_at` | 最近一次人工质量核对时间 |
| `max_quality_review_age_days` | 质量核对最长有效天数，超过后自动阻断 |
| `failure_alert_reference` | 同步失败告警规则或工单流程的证据引用 |
| `correction_procedure_reference` | 人工更正、复核和留痕流程的证据引用 |

下列任一情况会把冲突检查降为 `COVERAGE_LIMITED`，并阻止以“未发现匹配记录”放行：

- 来源没有被确认为权威来源；
- 同步方式不受支持或最近同步超过最大延迟；
- 字段覆盖率低于阈值；
- 重复率高于阈值；
- 缺少质量责任人或核对时间；
- 索引记录数、缺失数、版本或对账证据不一致。

## 4. 上线顺序

1. 由律所完成并签署 PD-01 至 PD-07 决策物，确定适用规则和责任人。
2. 在隔离环境导入权威档案，完成四类来源的索引构建、数量对账和质量测量。
3. 由主任/管理合伙人或合规负责人在“冲突治理”提交已冻结的材料包；另一职责人员核对摘要后独立确认。系统只在双人确认完成后生成正式政策版本，不允许原地修改材料或确认记录。
4. 由独立冲突核查人在“冲突治理”登记四类来源的范围、索引运行和质量证据；责任人按姓名选择，索引运行编号和来源版本必须来自导入对账报告，不得由界面自行生成。
5. 停用全部演示账号，确认主体身份明文已完成加密回填。
6. 检查 `/health/ready`。只有全部门禁通过后，才能进入真实账号的 A/B/冲突核查人隔离验收。
7. 使用完全虚构的数据完成 AT-01 至 AT-12；在律所书面放行前不得导入真实客户或真实案件。

## 5. 运维处置

- 同步失败或超过延迟：停止新的冲突放行，修复同步并重新对账，不得手工把状态改回 `COMPLETE`。
- 质量指标不达标：登记缺口和责任人，修复源数据后重新构建索引。
- 政策到达复核日或到期：创建并批准新版本；不得修改旧版本日期延长有效期。
- 发现批准人、材料引用或摘要错误：旧记录保留，新建更正版本并在审计材料中说明原因。
- 出现多个当前有效政策：生产保持未就绪，先由合规负责人核对版本生效区间。
