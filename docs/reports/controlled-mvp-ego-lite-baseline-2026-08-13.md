# 受控试用 MVP ego-lite 验收基线报告

> 验收日期：2026-08-13
> 验收分支：`codex/controlled-mvp-readiness`
> 报告口径：本地隔离环境与真实浏览器任务空间验收，不等同于生产上线批准

## 一、结论

| 判定对象 | 结论 | 说明 |
|---|---|---|
| 受控试用 MVP 候选的本地技术门禁 | **GO（仅虚构数据、固定夹具）** | 五角色在真实后端上的回看、冲突、权限、待办和降级场景已验证；本轮未在 UI 实际提交新的完整写入闭环。 |
| 真实律所生产发布 | **NO-GO** | 尚缺目标环境、真实律所治理决策、真实档案对账、生产安全配置及目标环境就绪证据。 |
| GitHub 远端 CI | **待确认** | 本地已按 CI 命令验证；仍需在 PR 上观察 GitHub Actions 的实际运行结果。 |

本结论仅表示“受控试用 MVP 候选的本地技术门禁 GO（仅虚构数据、固定夹具）”，允许继续进入远端 CI 和试用前验收。它不表示 Issue #6 已全部关闭，也不授权处理真实客户案件或向生产环境发布。

## 二、验收范围与环境

### 2.1 范围

本轮验收覆盖：

- 律师工作台、案件清单、利益冲突复核和审批提示；
- 律师之间的案件数据隔离；
- 独立冲突核查人的受限证据、回避声明和人工复核门禁；
- 助理待办中心；
- 财务模块在 MVP 范围外的明确提示与接口状态；
- 未登录深链、登录失败反馈和 390×844 移动端布局；
- QA 夹具重复写入、真实后端健康检查和 CI 测试门禁。

本轮真实 ego-lite 使用固定 QA fixture，覆盖 dashboard、案件回看、冲突复核、权限隔离、助理待办和财务降级提示；**未在 UI 中实际提交一条新的“新建接案 → 冲突检查 → 审批 → 回看”写入闭环**。该项仍属于 Issue #6，须在远端或正式试用前完成，不能由固定夹具回看证据替代。

### 2.2 隔离环境

验收使用临时 PostgreSQL、Redis、后端和前端端口，未复用或写入本机已有的默认数据库与缓存服务。验收结束后，临时监听端口均已关闭，原有默认端口监听保持不变。

Docker daemon 在本轮检查中无响应，因此使用本机 PostgreSQL 16.10 二进制和无持久化 Redis 建立等价的隔离验证环境。Elasticsearch 未启动，应用按非生产设计使用数据库搜索回退。

## 三、五角色真实 ego-lite 验收

所有角色均通过真实登录表单进入应用，数据来自临时真实后端与 PostgreSQL 的固定虚构夹具，而非前端模拟接口。本节证明回看和权限边界可用，不证明新的端到端业务写入已经通过 UI 完成。

| 角色 | 场景 | 结果 |
|---|---|---|
| 律师甲 | 打开工作台 | 显示 1 个数据库案件、1 个冲突任务、1 个待审批事项，数据源显示已连接。 |
| 律师甲 | 查看案件清单 | 仅显示本人负责的虚构验收案件。 |
| 律师甲 | 查看利益冲突 | 显示 1 条中风险、待人工复核记录；页面明确提示未完成独立复核前不得继续接案。 |
| 律师甲 | 访问财务中心 | 页面明确显示无权访问；对应接口返回 HTTP 403。 |
| 律师乙 | 查看案件清单 | 仅显示律师乙负责的隔离演练案件。 |
| 律师乙 | 直接访问律师甲案件 | 接口返回 HTTP 403 `FORBIDDEN`；页面不披露受保护案件详情。 |
| 独立冲突核查人 | 查看冲突队列和详情 | 任务、结果、复核人指定关系均可读取；页面显示受限命中、回避声明和人工复核门禁。 |
| 助理 | 查看待办中心 | 页面和真实接口均显示恰好 1 条“协助整理星河智联冲突复核材料”待办。 |
| 财务 | 访问财务中心 | 页面明确说明“财务中心未纳入本次 MVP 试用范围”；接口返回 HTTP 503 和 `MVP_MODULE_UNAVAILABLE`。 |

补充场景：

- 未登录访问受保护案件深链时自动返回登录页；
- 错误密码不会产生登录会话，并明确提示“账号或密码错误”；
- 移动端初检发现隐藏侧栏仍占用桌面宽度，修复后在 390×844 下主内容宽度为 358px、左右边界正常且无横向溢出；
- ego-lite 任务空间已按工具规范关闭，完成结果为 `done: true`。

## 五、发现并修复的问题

| 问题 | 影响 | 修复与验证 |
|---|---|---|
| CI 缺少真实后端运行冒烟 | Mock 浏览器测试无法证明根后端、迁移和真实登录可运行 | 新增 PostgreSQL/Redis 服务、schema bootstrap、五角色登录、助理待办、403/503 边界和健康检查。 |
| QA fixture 二次写入失败 | 重复 seed 时结构化冲突结果无法写回 PostgreSQL | 显式序列化 JSON；连续 seed 两次并 verify 通过。 |
| runtime-smoke 未远端守护幂等性 | 本地发现的幂等修复可能后续回归 | CI 改为连续执行 `seed → seed → verify`。 |
| 助理账号没有可验收待办 | 登录成功但无法验证 inbox 业务闭环 | fixture 新增 1 条确定性虚构待办，真实 API 与 UI 均验证为 1 条。 |
| 390px 下主内容被桌面侧栏挤压 | 页面无滚动条但实际不可读 | 移动断点清除隐藏侧栏占位，并新增 Playwright 防回归测试。 |
| 并发便捷 API 将同一任务入队两次 | 数据库、文件、API 或批处理回调可能重复执行 | 移除前置提交，只保留一次 submit-and-wait；race 测试验证每项恰好执行一次。 |
| auth 测试依赖共享 Redis 6379 | 测试可能污染开发缓存或在无 Redis 时失败 | 测试辅助代码改用进程内 miniredis。 |
| 并发测试存在数据竞争和调度依赖 | CI `-race` 必然失败或偶发 panic | 使用原子计数/锁保护观测数据，并确定性占用 worker 后测试满队列。 |
| PR 评论缺少写权限 | 测试全绿后 summary job 仍可能因评论失败 | `test-summary` 使用最小 `contents: read`、`issues: write` 权限；fork PR 安全跳过评论。 |

## 六、剩余风险与生产门禁

以下事项不改变固定夹具下的本地技术候选门禁结论，但仍须在远端或正式试用前完成，并继续阻塞生产放行：

1. **Issue #6 的新写入闭环尚未完成**：须使用真实 UI 新建一条虚构接案，依次完成冲突检查、审批和回看，并保存网络与页面证据；本轮固定夹具回看不能替代该项。
2. **远端 CI 尚未执行**：需在 PR 上确认所有 GitHub Actions job 的真实名称和结果。
3. **Docker Compose 未完成本轮运行验证**：本机 Docker daemon 无响应；隔离进程验证不能替代最终编排验证。
4. **Elasticsearch 未纳入本轮真实服务栈**：仅验证了非生产数据库回退路径。
5. **真实律所治理未完成**：尚缺政策双签、独立核查人任命、角色分离、例外与豁免规则等正式材料。
6. **真实档案与身份数据未验收**：尚缺案件、客户、主体及关联关系档案的导入、质量检查、对账和加密回填证据。
7. **目标环境未验收**：尚缺生产 PostgreSQL TLS、备份恢复、密钥、真实账号反向越权测试及目标 `/health/ready` 健康响应。
8. **绝对墙钟性能测试对机器负载敏感**：建议后续使用多次采样或独立性能作业，避免将 CI 调度抖动误判为产品回归。
