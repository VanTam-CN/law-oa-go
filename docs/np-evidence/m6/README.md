## 回滚范围

`89f2eb9` 与 `49e5c15` 的应用源码相同，构建嵌入的提交与二进制散列不同。本演练覆盖这对构建之间的切换及助手关闭后的历史合同，更早的无保护版本只允许在升级前的 v14 阶段运行。PG 与 Redis 在应用切换中持续运行。PG 使用独占的临时存储。此处的重启指根应用进程。

## 复跑

在本分支的干净工作树执行，要求回环端口 18789、18790 可用，Docker、Go 和 psql 满足 M5 的同版本要求。每次独立运行使用新的私有临时目录。历史应用从三个固定提交的干净克隆构建。

```bash
export NP_M5_WORK="$(mktemp -d /tmp/np-m5.m6.XXXXXXXX)"
bash scripts/np-m6/rehearse.sh prepare
bash scripts/np-m6/rehearse.sh exercise
bash scripts/np-m5/environment.sh clean
```

原始日志、令牌、合成表单、行内容及请求键仅在该运行的私有目录使用。开发分支只归档脱敏计数、判定、指纹及生命周期。I09-FILES 后置；原生接案号同秒碰撞继续单列 Hermes `t_a4646b57`。
