## 验收依据

旧树必须以 Go 退出码 1、指定测试失败及包失败结束，且失败输出必须含预写缓存的 203、命中标记头与紧随缓存正文的下游标记。新树分别核对具名测试的开始、通过次数和包成功终态。中间件整包另启用竞态检测，最后编译根程序。

协调者逐步重放最终工作流，并以保存的 Go 事件验证判断逻辑。普通编译诊断可以与成功测试共存。删除一次通过事件、替换包名、插入跳过事件、删除包成功终态或插入构建失败事件，五项对照均使检查退出 1。执行层和结果检查层分别保留失败状态。

本次范围不包含全量 I11、PGO 采样、部署或真实试用。合并、部署和真实试用继续 **HOLD**。
