## 策略

旧卡 `t_af5c899a` 的候选基于 `10ce908`，还涉及响应头捕获、未命中回填和 lint 配置。本分支从 #52 已验源码独立修复，仅采用命中短路和对应回归。Docker 资源调查是只读本机事项，机器资源清单未纳入 Git。
