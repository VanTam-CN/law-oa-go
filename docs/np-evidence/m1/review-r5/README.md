截断保护以事务中实际存量和服务端匹配到的既有行 ID 为准。超过 20 个主体时，旧式全量 PUT 只有保留全部既有主体才能保存，适用于无法表达删除意图的旧协议。精度规则在接案和主体两个写入点共用；浏览器舍入后无法辨明位置的数组编辑会被拒绝。
