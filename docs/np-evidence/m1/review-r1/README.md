## 复验范围

四个 glm-flash 子任务分别参与前端、浏览器回归、主体保全和异步检测。主调度复现基线、调整实现、核对请求和数据库终态，并在同一代码提交重新执行回归。Go 定点测试启用 `-race -count=1`，通过 48 个顶层用例，含子测试共 73 项，跳过 0 项；旧证据中的 55 项全部按名称保留。Chrome 通过 14 条，其中 9 条为既有回归，5 条为本轮场景。Jest 通过 16 项，TypeScript 检查、前端构建和 Go 构建均通过。逐命令 SHA、参数、起止时间、退出码及测试名单见 [结构化证据](verification.json)。

Chrome 使用合成 HTTP 响应。共享 Gin 路由及正式异步服务的数据库证据来自回环临时 PostgreSQL 16.14。异步测试仅在风险评估中暂停以控制先后顺序，沿用正式检测、证据写入和关联事务。后续真人试用、集成 CI、M2 及合并部署不在本轮执行范围内。历史创建请求重放命中后重新绑定本机旧正文的条件风险在原审核卡单列，本轮范围为已有草稿。
