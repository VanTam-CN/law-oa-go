## 单元素外层的协议边界

对于原值 `[[9007199254740993]]`，从同一个 GET、同一版本执行以下两种操作，原生客户端序列化出的 PUT 内容逐字节相同，数组部分均为 `[[9007199254740992,7]]`。

- 在原子数组内追加 7，期望保留 9007199254740993。
- 删除唯一子数组，再添加 `[9007199254740992,7]`，期望保留新输入的 9007199254740992。

当前协议按第一种解释返回 200、保留原整数并升版。旧协议没有操作意图字段，无法对第二种意图同时作出精确保全承诺。两个入口的替换意图探针仍记录为预期失败，单列于运行证据，本轮未扩展协议。
