# Header keyboard accessibility plan

## Problem

Header fullscreen, notification, and user menu controls are div elements with tabIndex -1. Keyboard and screen-reader users cannot reliably reach notifications or logout.

## Goal

All header actions must be keyboard operable, understandable, and have stable visible focus and target size.

## Acceptance

- Tab order reaches fullscreen, notification, and user menu controls.
- Enter/Space activates fullscreen and opens notification and user menu.
- Escape and an outside click close menus and return focus to their triggers.
- Controls expose accessible names, expanded/pressed states, menu semantics, and visible focus.
- The login password visibility action remains a named, keyboard-operable button with synchronized state.
- Header tests and type-check pass.
- Real browser keyboard validation passes.
