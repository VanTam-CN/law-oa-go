## 📋 概述

本文档是 Law OA Go 项目文档的入口索引。仓库中保留了不少历史审计、阶段报告和计划文档；新接手时优先阅读下列“当前文档”，再按需查阅历史材料。

## 当前文档入口

| 场景 | 首选文档 | 说明 |
|------|----------|------|
| 项目总览 | `README.md` | 当前版本、技术栈、快速启动、模块状态 |
| 实际功能状态 | `docs/feature-status-actual.md` | 按代码审计更新的模块完成度 |
| 架构理解 | `docs/architecture-overview.md` | 当前目录、入口、数据流和部署形态 |
| API 快速入口 | `docs/API.md` | 主要路由组、认证和响应格式 |
| 配置和环境变量 | `docs/CONFIGURATION.md` | `godotenv` + `viper` 配置方式 |
| 开发者上手 | `docs/DEVELOPER_GUIDE.md` | 本地开发、迁移、测试和构建命令 |
| 部署 | `docs/DEPLOYMENT.md` | Docker/Kubernetes/Helm 生产部署 |

## 历史文档提示

- `docs/feature-status.md`、`docs/feature-status-updated.md`、多个 sprint completion 报告和 2025 年项目审计文档保留为历史记录。
- 若历史文档与代码或上表当前文档冲突，以代码和当前文档为准。
