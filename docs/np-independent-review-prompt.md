## 重点二：防覆盖

- 原生共用保存是否仅更新 description；遗漏、null、空串、clear_fields、未知/重复字段、材料和主体意图是否按合同处理。逐字保留空格、未知 metadata 的大整数/小数、主体 ID/身份引用、材料两版记录和附件。

## 重点三：断线防重复

- 保存与显式放弃是否共用 actor+原键的 PG 事务锁和唯一约束，并在任何业务写入之前取得。检查 digest、锁顺序、事务上下文、回滚及最终权限重验。
